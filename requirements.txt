# Multimodal AI Financial Assistant — RUNTIME dependencies (api.py + src/)
#
# RULE 1 (rules.md): every line here is free. No paid tiers, no credit card, no license keys.
# Cost annotation is mandatory on every dependency.
#
# This file is what gets installed in the 512 MB deployment, so it holds only what the
# FastAPI backend imports. The Streamlit dashboard, the eval suite and the test tooling
# live in requirements-dev.txt — together they pulled ragas, datasets, pyarrow, streamlit
# and pandas into a container that never imports any of them.
#
# After a successful install, freeze exact versions:
#     pip freeze > requirements.lock.txt
# requirements.txt holds intent; requirements.lock.txt holds reproducibility.

# ── Orchestration ─────────────────────────────────────────────────────────────
# LangChain Expression Language: chain composition, streaming, callbacks, tracing.
# Cost: $0 (MIT/OSS). Local.
langchain>=0.3.0,<0.4
langchain-core>=0.3.0,<0.4
langchain-community>=0.3.0,<0.4

# ── Document parsing (LOCAL, CPU, no models) ──────────────────────────────────
# pdfplumber: text and table extraction from a PDF's own text layer, with coordinates.
# Cost: $0 (MIT). Pure Python over pdfminer.six — no model weights, no torch.
#
# Replaced Docling in the 512 MB refactor. Docling was better: TableFormer recovered
# tables from unruled layouts and RapidOCR read scanned pages. Both are neural models,
# and torch alone is ~300 MB resident before a page is parsed. What is lost is stated in
# src/parser.py rather than implied here: unruled tables and all scanned/image input.
pdfplumber>=0.11.0

# PDF page rendering for the previewer, and the millisecond text-layer triage.
# Cost: $0 (AGPL/commercial dual — AGPL is fine for this project; we do not redistribute).
pymupdf>=1.24.0

# ── Vector store (LOCAL, on-disk) ─────────────────────────────────────────────
# ChromaDB embedded PersistentClient. No server, no Docker, no cloud account.
# Chosen over FAISS for metadata filtering (FR-3.4). Cost: $0 (Apache-2.0).
chromadb>=0.5.0

# ── Embeddings (CLOUD, FREE TIER) ─────────────────────────────────────────────
# sentence-transformers/all-MiniLM-L6-v2, served by the HuggingFace Inference API rather
# than loaded in-process. Same model, same 384 dimensions, so existing Chroma collections
# stay readable. Cost: $0 (free tier, rate-limited). Needs HF_TOKEN.
#
# This REVERSES decision D-2 and the guarantee that financial text never leaves the
# machine at embed time: chunk text is now sent to the endpoint. The trade buys the
# ~300 MB that torch + sentence-transformers occupied. EMBEDDING_ENDPOINT_URL points the
# same code at a self-hosted Text Embeddings Inference server if locality matters more.
langchain-huggingface>=0.1.0

# ── LLM provider (CLOUD, FREE TIER) ───────────────────────────────────────────
# Groq: reasoning. Free tier, no credit card required.
# Model IDs are NOT pinned here — they live in src/config.py (decision D-4). Cost: $0.
langchain-groq>=0.2.0
groq>=0.11.0

# ── Configuration ─────────────────────────────────────────────────────────────
# Cost: $0 (MIT).
pydantic>=2.8.0
pydantic-settings>=2.4.0
python-dotenv>=1.0.0

# ── Observability ─────────────────────────────────────────────────────────────
# LangSmith tracing. Free tier, 5k traces/month. OPTIONAL at runtime — the app must
# run normally when LANGCHAIN_API_KEY is absent (D-11). Cost: $0.
langsmith>=0.1.100
